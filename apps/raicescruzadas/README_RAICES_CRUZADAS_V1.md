# Raíces Cruzadas V1

Juego HTML/CSS/JS autónomo de crucigramas coleccionistas.

## Cómo subirlo

Sube la carpeta completa `raicescruzadas` dentro de `apps/`:

```text
apps/raicescruzadas/index.html
```

## Incluye

- Crucigrama por categoría única.
- Mundo mixto.
- Multiverso.
- Personalizado.
- Expedición con eventos y boss.
- Códex.
- Colección por álbumes.
- Matemonario con 53 imágenes.
- Cajas.
- Tienda con conversión de recursos.
- Armario blindado: quitar por ranura, desequipar todo y reparar.
- Logros.
- Perfil.
- Opciones de diagnóstico: reparar, exportar, importar, borrar progreso y recursos de prueba.

## Recursos garantizados

- Semillas: resolviendo palabras, completando crucigramas, logros y conversiones.
- Llaves de vivero: completando crucigramas, perfectos, tienda y recompensas.
- Llaves prohibidas: bosses, conversión 3 llaves normales, compra por semillas y logros.
- Polvo: repetidos.
- Fragmentos Matemon: Matemon repetidos.

## Pistas

El juego no genera pistas durante la partida. Usa el banco `src/data/gameData.js`, preparado con campo `clue` y `clueExtra`.

## Nota de V1

Esta versión prioriza estabilidad, sistemas completos y economía permisiva. El contenido se puede ampliar editando `src/data/gameData.js` o sustituyéndolo por un banco revisado más grande.
