# AhorKDo IA 4: Última Letra

Roguelike educativo de palabras ocultas en Phaser 3, listo para GitHub Pages.

## Cambios de esta versión

- Se elimina la generación automática de palabras durante la partida.
- Todas las soluciones salen de bancos fijos revisados por categoría.
- Nuevo **Mercado Negro IA**: los Datos IA ganados en las runs se guardan y sirven para comprar Civilians que faltan en la colección.
- Más logros de coleccionismo: Civilians, familias, Codex IA, compras y categorías.
- Botones de Música y Efectos directamente en el menú principal.
- Más variedad de música y efectos generados con WebAudio.
- Conserva powerups visibles y activables durante los rescates.

## Subida a GitHub Pages

Sube todo el contenido de esta carpeta a `apps/ahorkdoia3/` o cambia la ruta según tu web.

No requiere instalación: Phaser se carga por CDN desde `index.html`.


## Versión 4
