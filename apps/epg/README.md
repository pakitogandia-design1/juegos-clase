# EPG: Espejo Pistola Gancho — La Cámara de la Incógnita

Juego arcade educativo en Phaser 3 para practicar ecuaciones de primer grado.

## Cómo subirlo a GitHub Pages

1. Sube todo el contenido de esta carpeta a un repositorio de GitHub.
2. En el repositorio, entra en Settings → Pages.
3. En “Build and deployment”, elige “Deploy from a branch”.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda. GitHub generará la URL pública.

No necesita instalación. Phaser se carga por CDN.

## Estructura

- `index.html`: entrada del juego.
- `src/`: código modular.
- `styles/style.css`: estilos base.
- `assets/`: carpeta reservada para imágenes y audio si se añaden más adelante.

## Controles

- Ratón o pantalla táctil.
- Elige herramienta, operación, número y lado.
- El espejo replica siempre la misma operación en ambos lados.
