# Audio

Esta carpeta está preparada para añadir efectos de sonido externos si se desea.

En esta versión, los efectos de sonido se generan desde el propio código con Web Audio API, por eso no hay archivos `.mp3`, `.wav` u `.ogg`.

La opción **Sonido: Activado / Desactivado** del juego controla estos efectos generados por código.
